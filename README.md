# UEFA 네이션스리그 대시보드

UEFA 네이션스리그의 순위표, 경기 일정·결과, 팀별 최근 5경기 기록, 경기 미리보기를 한 화면에서 볼 수 있는 한국어 대시보드입니다.

> A Korean-language dashboard for the UEFA Nations League: live standings, fixtures & results, last-5 form (all competitions), team stats and match previews. No API key, no dependencies.

## 주요 기능

- **순위표**: 리그 A~D 전체 조의 경기·승·무·패·득실·승점
  - 8강 진출, 승격, 플레이오프, 강등 구간을 색으로 표시
  - 팀별 **최근 5경기(모든 대회 기준)** 승/무/패 흐름
- **경기 일정·결과**: 날짜별 목록, 리그와 상태(예정/진행 중/종료) 필터, 경기 중 1분마다 자동 갱신
- **라인업**: 경기를 누르면 포메이션과 선발 11명을 경기장 그림으로 표시 (선수 한국어 이름·사진)
  - 끝난 경기·진행 중 경기: 득점자, 득점·경고·퇴장, 교체 시간, 교체 명단
  - 예정 경기: 발표되면 선발 명단, 발표 전에는 두 팀의 직전 경기 선발 라인업(참고용)
- **경기 미리보기**: 경기를 누르면 다음 정보를 비교
  - 두 팀의 순위, 승점, 득실차
  - 최근 5경기 기준 경기당 득점·실점, 무실점 경기, 2.5골 오버, 양팀 득점 비율
  - 맞대결 기록
- **팀 분석**: 최근 5경기 또는 10경기 기록과 지표, 이번 시즌 네이션스리그 성적, 다음 경기 일정
- PC와 모바일 화면 지원, 다크 모드 지원

## 사용 방법

### 방법 1: 파일만 열기 (가장 간단)

`static/index.html` 파일을 더블클릭해서 브라우저로 엽니다. 설치할 것이 없습니다.

### 방법 2: 로컬 서버로 실행

[Python 3.8 이상](https://www.python.org/downloads/)이 필요합니다. 외부 패키지는 쓰지 않습니다.

```bash
python app.py
```

Windows에서는 `run.bat`을 더블클릭해도 됩니다. 브라우저가 자동으로 `http://127.0.0.1:8765/`를 엽니다.

서버로 실행하면 데이터를 잠시 저장(캐시)해 두기 때문에 새로고침이 더 빠릅니다.

| 옵션 | 설명 |
| --- | --- |
| `python app.py --no-browser` | 브라우저를 자동으로 열지 않음 |
| `PORT=9000 python app.py` | 포트 변경 (기본 8765). Windows PowerShell에서는 `$env:PORT=9000; python app.py` |

## 파일 구성

```
app.py             로컬 서버 (Python 표준 라이브러리만 사용, 데이터 캐시)
static/index.html  화면 전체 (HTML/CSS/JS 한 파일). 서버가 없으면 ESPN에서 직접 데이터를 받아옴
run.bat            Windows용 실행 파일
```

## 데이터 출처와 한계

- 데이터는 ESPN의 공개 웹 API(`site.api.espn.com`)에서 가져옵니다. **공식 문서가 없는 API라서** 예고 없이 형식이 바뀌거나 막힐 수 있습니다.
- 선수 한국어 이름과 사진은 [위키데이터](https://www.wikidata.org/)에서 영어 이름으로 찾아옵니다. 위키데이터에 없는 선수는 영어 이름, 사진이 없는 선수는 등번호로 표시합니다. 사진은 위키미디어 공용(Commons)에 올라온 이미지이며, 각 이미지의 라이선스는 원본 페이지를 따릅니다.
- 최근 경기는 각 팀의 최근 약 25경기 범위만 조회합니다. 그보다 오래된 맞대결은 나오지 않습니다.
- 승부차기, 몰수 경기 같은 특수한 결과는 ESPN이 표시하는 대로 나옵니다.
- 시간은 사용하는 컴퓨터의 시간대로 표시됩니다.
