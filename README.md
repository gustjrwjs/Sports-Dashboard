# SPORTS LIVE! (축구 · 농구 · 야구)

<img src="static/icons/icon-192.png" width="96" alt="SPORTS LIVE! 아이콘">

여러 리그의 순위표, 경기 일정·결과, 팀별 최근 5경기 기록, 라인업·선수 기록, 경기 미리보기를 한 페이지에서 볼 수 있는 한국어 대시보드입니다. 화면 위쪽에서 종목별로 묶인 리그를 골라 바꿉니다.

> A Korean-language sports dashboard: Premier League, La Liga, Serie A, Bundesliga, UEFA Champions League, Europa League, Nations League, NBA and MLB in one page. Live standings, fixtures & results, last-5 form, lineups / box scores and match previews. No API key, no dependencies.

## 주요 기능

- **순위표**: 리그별 기본 지표와 함께 팀별 **최근 5경기** 승/패 흐름
  - 축구: 경기·승·무·패·득실·승점
  - 농구·야구: 승·패·승률·게임차·홈/원정·최근 10경기·연승/연패
- **경기 일정·결과**: 네이션스리그는 시즌 전체, 나머지 리그는 주 단위(이전 주·다음 주 이동). 클럽의 최근 경기에는 챔피언스리그·컵 대회도 포함하고 친선경기는 뺍니다. 상태(예정/진행 중/종료) 필터, 경기 중 1분마다 자동 갱신
- **LIVE 탭**: 지금 진행 중인 경기만 크게 모아 보여주고, 경기 중에는 **20초마다 자동으로 점수를 새로 받아옵니다**. 점수가 바뀐 경기는 빨갛게 반짝입니다.
  - 축구: 득점자·퇴장 선수
  - 농구: 쿼터별 점수
  - 야구: 주자 상황·아웃 카운트·볼카운트, 현재 타자·투수
  - 배당·기준점: 승(무)패, 핸디 기준점, 언더/오버 기준점과 배당(소수점), 현재 점수로 어느 쪽이 맞고 있는지 표시. 경기 상세 창에도 나옵니다.
    ESPN이 제공하는 **DraftKings(미국) 경기 전 기준** 값이라 프로토·국내 사이트 배당과 다를 수 있습니다.
  - 오늘 곧 시작하는 경기와 최근 끝난 경기도 함께 표시
- **★ My 경기**: 경기 카드 오른쪽 위 ☆를 누르면 담깁니다. 여러 리그 경기를 섞어 담을 수 있고, My 경기 탭에서 담은 경기만 진행 중·예정·결과로 나눠 보여줍니다. 진행 중이면 20초마다 자동 갱신, 끝나면 최종 점수와 배당 적중 여부(초록색)를 표시합니다. 담은 목록은 그 기기에만 저장되며 7일 뒤 자동으로 정리됩니다.
- **🏆 토너먼트 대진표**: 챔피언스리그·유로파리그(16강~결승, 녹아웃 PO 따로), 네이션스리그 파이널(8강~결승, 3·4위전), NBA 플레이오프, MLB 포스트시즌. 순위표 탭 위 [순위표 | 토너먼트] 전환. 두 경기 라운드는 합계 점수, NBA·MLB는 시리즈 승수. 이번 시즌 토너먼트 전에는 지난 시즌 대진표 표시
- **💬 커뮤니티**: 🏆 자랑하기 · 🙋 문의 게시판과 ❓ FAQ. 가입 없이 닉네임만 정해서 글·댓글·사진(자랑하기)을 올리고, 추천할 수 있음. 문의에는 운영자가 🛡 운영자 답변을 달 수 있음. 게시판 데이터는 Supabase(무료)에 저장 → 아래 '커뮤니티 게시판 켜기' 참고
- **끝난 경기 표시**: 이긴 팀에 빨간 **승** 표시, 농구·야구는 합산 점수도 함께 표시
- **경기 상세**: 경기를 누르면 아래 내용을 보여줍니다.
  - 축구: 라인업과 득점자. 라인업 발표 전에는 두 팀의 직전 경기 선발(참고용)
  - 농구·야구: 선수 기록, 부상자, 선발 투수
  - 두 팀 비교: 순위, 시즌 성적, 최근 5경기 득점·실점 등
  - 맞대결 기록
- **선수 한국어 이름·사진**: 위키데이터에서 찾아 표시 (NBA·MLB는 ESPN 선수 사진 우선)
- **팀 분석**: 최근 5경기 또는 10경기 기록과 지표, 이번 시즌 성적, 다음 경기 일정
  - **주목할 선수**: 이번 시즌 기록이 좋은 선수 4명과 핵심 스탯 (축구: 출전·골·도움·유효슈팅, 농구: 경기당 득점·리바·어시·야투%, 야구: 타자 2명·투수 2명)
  - **부상·결장 선수**: 팀 창을 열 때마다 ESPN 최신 부상 보고를 불러옴. 보고 이후 경기에 뛰었으면 '복귀'로, 최근 경기에 뛰었지만 새 보고가 있으면 출전 기록을 함께 표시
  - **최신 뉴스**: 접어 두었다가 눌러서 펼쳐 보는 ESPN 기사 목록 (영어)
- 리그 선택은 주소에 남습니다. 예: `.../static/#nba` 링크를 보내면 NBA 화면이 바로 열립니다. 주소 이름: `#epl` `#laliga` `#seriea` `#bundesliga` `#ucl` `#uel` `#unl` `#nba` `#mlb`
- PC와 모바일 화면 지원, 다크 모드 지원

## 사용 방법

### 휴대폰 앱으로 설치 (추천)

앱스토어 없이 링크만으로 설치하는 웹 앱(PWA)입니다. 지인에게는 아래 링크만 보내면 됩니다.

👉 **https://gustjrwjs.github.io/Sports-Dashboard/static/**

- **안드로이드 (Chrome)**: 링크를 열고 위쪽 **앱 설치** 버튼을 누르거나, Chrome 메뉴 **⋮ → 앱 설치(홈 화면에 추가)** 를 누릅니다.
- **아이폰 (Safari)**: 링크를 Safari로 열고 **공유 버튼 → 홈 화면에 추가 → 추가** 를 누릅니다.
- 카카오톡에서 링크를 누르면 카카오톡 안의 브라우저로 열리는데, 거기서는 설치가 안 됩니다. 메뉴에서 **다른 브라우저로 열기**(아이폰은 Safari로 열기)를 누른 뒤 설치하세요.

설치하면 홈 화면 아이콘으로 바로 열리고 주소창 없이 앱처럼 보입니다. 새 버전은 다음에 열 때 자동으로 반영됩니다.

### 방법 1: 파일만 열기 (가장 간단)

`static/index.html` 파일을 더블클릭해서 브라우저로 엽니다. 설치할 것이 없습니다.

### 방법 2: 로컬 서버로 실행

[Python 3.8 이상](https://www.python.org/downloads/)이 필요합니다. 외부 패키지는 쓰지 않습니다.

```bash
python app.py
```

Windows에서는 `run.bat`을 더블클릭해도 됩니다. 브라우저가 자동으로 `http://127.0.0.1:8765/`를 엽니다.

서버는 ESPN 데이터를 잠시 저장(캐시)해 두기 때문에 새로고침이 더 빠릅니다.

| 옵션 | 설명 |
| --- | --- |
| `python app.py --no-browser` | 브라우저를 자동으로 열지 않음 |
| `PORT=9000 python app.py` | 포트 변경 (기본 8765). Windows PowerShell에서는 `$env:PORT=9000; python app.py` |

### 커뮤니티 게시판 켜기 (Supabase)

게시판 글은 모든 방문자가 같이 봐야 해서 무료 데이터베이스 서비스 [Supabase](https://supabase.com/)를 씁니다. 설정 전에는 게시판이 '준비 중'으로 나오고 FAQ만 보입니다.

1. Supabase에 가입하고 새 프로젝트를 만듭니다 (무료 플랜).
2. 대시보드 **SQL Editor**에 [`supabase_setup.sql`](supabase_setup.sql) 내용을 붙여넣고, 맨 아래 관리자 비밀번호를 바꾼 뒤 **Run**.
3. **Project Settings → API**에서 Project URL과 `anon` `public` 키를 복사해 `static/index.html`의 `const SB = {url:"", key:""};`에 넣습니다. (anon 키는 브라우저용 공개 키라 넣어도 됩니다. `service_role` 키는 절대 넣지 마세요.)
4. 운영자 모드: 커뮤니티 → FAQ 맨 아래 '운영자' → 2번에서 정한 비밀번호.

## 파일 구성

```
app.py             로컬 서버: 화면 제공 + ESPN 요청 전달·캐시 (Python 표준 라이브러리만 사용)
static/index.html  화면 전체 (HTML/CSS/JS 한 파일). 리그 설정은 맨 아래 스크립트의 LEAGUES에 있음
static/manifest.webmanifest, static/sw.js, static/icons/
                   휴대폰 앱 설치(PWA)용 설정·서비스 워커·아이콘
supabase_setup.sql 커뮤니티 게시판용 Supabase 데이터베이스 설정 (테이블·보안 규칙·함수·사진 저장소)
run.bat            Windows용 실행 파일
```

## 데이터 출처와 한계

- 경기 데이터는 ESPN의 공개 웹 API(`site.api.espn.com`)에서 가져옵니다. **공식 문서가 없는 API라서** 예고 없이 형식이 바뀌거나 막힐 수 있습니다.
- 선수 한국어 이름과 사진은 [위키데이터](https://www.wikidata.org/)에서 영어 이름으로 찾아옵니다. 한국어 레이블이 없으면 한국어 위키백과 문서 제목을 씁니다. 찾지 못한 선수는 영어 이름, 사진이 없는 선수는 등번호로 표시합니다. 사진은 위키미디어 공용(Commons)에 올라온 이미지이며, 각 이미지의 라이선스는 원본 페이지를 따릅니다.
- 맞대결 기록은 각 팀의 최근 경기 일정 범위 안에서만 찾습니다.
- 승부차기, 연장전, 몰수 경기 같은 특수한 결과는 ESPN이 표시하는 대로 나옵니다.
- 시간은 사용하는 컴퓨터의 시간대로 표시됩니다.
